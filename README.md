 ## Travel App

An Android Travel Application built using **Java, Firebase, RecyclerView, and Glide**.  
The app allows users to explore destinations, view details, and book tickets seamlessly.

##  Features
-  Explore popular travel destinations  
-  Detailed destination information  
-  Ticket booking system  
-  Smooth image loading with Glide  
-  Firebase backend integration
